# Kısa kurulum sırası

1. `scripts/publish-all.ps1` ile paketleri oluştur.
2. SQL Server Express bulunan bilgisayara sunucu paketini kur.
3. Panelde ekranı ve cihaz tokenını oluştur.
4. Ekrana bağlı bilgisayara Player paketini kur; aynı kod ve tokenı gir.
5. Panelden içerik yükle, oynatma listesi oluştur ve ekrana gönder.

Ayrıntılar: [Sunucu kurulumu](INSTALLATION.md) ve [Player kurulumu](PLAYER_SETUP.md).
